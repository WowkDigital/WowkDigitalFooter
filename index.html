📖 Szybki przewodnik wdrożenia (dla ludzi)

1

Dołącz skrypt z CDN

Umieść pojedynczy tag skryptu w sekcji <head> lub przed zamknięciem </body>:

<script src="https://cdn.jsdelivr.net/gh/WowkDigital/WowkDigitalFooter@latest/wowk-digital-footer.js"></script>
2

Zainicjalizuj stopkę

Wywołaj metodę WowkDigitalFooter.init() z wybraną konfiguracją Twojego projektu:

WowkDigitalFooter.init({
  siteName: 'Sivis Drive'
});
3

Inteligentny kontrast

Algorytm ITU-R BT.709 automatycznie obliczy luminancję tła i dobierze idealną czytelność tekstu i logo.

Pełna tabela parametrów konfiguracyjnych API

Parametr Typ Wartość domyślna Opis
siteName string 'Sivis Drive' Nazwa witryny/aplikacji, wyświetlana w sekcji praw autorskich (Copyright).
container string 'body' Selektor CSS elementu, do którego stopka zostanie dołączona (np. '#app', 'main').
brandName string 'Wowk Digital' Nazwa marki/firmy wyświetlana obok oficjalnego logo.
brandUrl string 'https://github.com/WowkDigital' Adres URL po kliknięciu w logo i nazwę marki.
showHubLink boolean true Czy pokazywać przycisk kierujący do centralnego katalogu aplikacji (WD HUB).
hubUrl string 'https://wowkdigital.github.io/WD_HUB/' Adres docelowy przycisku centralnego hubu aplikacji.
theme string 'auto' Motyw: 'auto' (automatyczny kontrast), 'light' (jasny) lub 'dark' (ciemny).

Własna stylizacja (Zmienne CSS)

Możesz nadpisać dowolną zmienną w arkuszu stylów CSS bez modyfikowania pliku JavaScript:

--wf-bg
Kolor tła stopki (domyślnie: transparent)
--wf-text
Kolor tekstu i copyright (domyślnie: #94a3b8 / #64748b)
--wf-brand
Kolor logo i nazwy marki (domyślnie: #f8fafc / #0f172a)
--wf-brand-hover
Kolor logo i marki po najechaniu kursorem (domyślnie: #ffffff / #000000)
--wf-accent
Kolor pulsującego serduszka (domyślnie: #ef4444)
--wf-border
Kolor górnej linii rozdzielającej (domyślnie: rgba(255,255,255,0.06))
