Step-by-Step Integration Guide

1

Include CDN Script

Include the script inside the <head> tag or right before the closing </body> tag:

<script src="https://cdn.jsdelivr.net/gh/WowkDigital/WowkDigitalFooter@latest/wowk-digital-footer.js"></script>
2

Initialize Footer

Initialize the footer using JavaScript with your custom configuration:

document.addEventListener('DOMContentLoaded', () => {
  WowkDigitalFooter.init({
    siteName: 'Your Site Name'
  });
});
3

Smart Contrast

The script automatically calculates background contrast and applies the optimal theme dynamically.

Configuration API Properties

Parameter Type Default Description
siteName string 'Sivis Drive' Site name shown in the copyright section.
container string 'body' CSS selector for the parent target element.
brandName string 'Wowk Digital' Brand/company name displayed next to the logo.
brandUrl string 'https://github.com/...' Target URL when clicking on the brand logo.
showHubLink boolean true Show or hide the button pointing to the WD HUB central projects directory.
hubUrl string 'https://...' Target URL of the central applications hub.
theme string 'auto' Color theme: 'auto' (smart contrast), 'light' or 'dark'.

Custom Styling (CSS Variables)

You can easily customize footer colors by overriding CSS variables in your project styles. No need to modify the JS file!

  • --wf-bg
    Footer background color. Default: transparent
  • --wf-text
    Text and copyright color. Default: #94a3b8 (dark) / #64748b (light)
  • --wf-brand
    Brand logo and name color. Default: #f8fafc (dark) / #0f172a (light)
  • --wf-brand-hover
    Brand logo hover color. Default: #ffffff / #000000
  • --wf-accent
    Animated heartbeat heart color. Default: #ef4444
  • --wf-border
    Top border line color. Default: rgba(255,255,255,0.06)
